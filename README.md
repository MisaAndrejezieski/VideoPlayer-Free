# 🎬 Video Player Anônimo

Player de vídeos com anonimato via proxies gratuitos.

## ✨ Funcionalidades

- Suporte a qualquer URL (YouTube, Vimeo, Twitch, etc)
- Anonimato com proxies gratuitos rotativos
- Interface PyQt5
- Player VLC embutido
